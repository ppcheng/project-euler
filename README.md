# Project Euler

## Development Setup

```bash
uv sync
```

### Linting & Formatting with Ruff

- **Check** the codebase before committing to catch style and correctness issues:

  ```bash
  uv run ruff check .
  ```

- **Format** the code automatically when needed (e.g., before pushing):

  ```bash
  uv run ruff format .
  ```
